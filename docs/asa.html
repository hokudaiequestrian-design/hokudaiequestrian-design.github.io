毎週の朝練なし（馬休日など）

朝練なしの日は、無断の数え方で出席にも数えません（増えも減りもしない）。その日は無断欠席を入れられません。
毎週の曜日にしていても、朝練があった日は、その日を開いて「この日は朝練があった」でその日だけ解除できます。

要注意（無断が続いている人）

    無断の日は1つ増え、出席した日（休みでも無断でもない日）は1つ減ります。休みの日は増えも減りもしません。残りがある間、毎朝ここに出ます。

    休み

      有給休暇・季節休み・体調不良（了承待ちも）。「決める」を押すと、その人の休みを了承・却下するところ（バイト・休みをまとめる）が開きます。

      無断欠席・体調不良

      来ていない人にチェック（何人でも）

      まだ選んでいません

      「体調不良に入れる」「有給を入れる」は、この日1日のぶんを了承ずみで入れます（左の「休み」に出て、× で外せます）。有給はその人の残りから1日減ります。季節休みや何日かの休みは、休みの欄の「決める」から入れてください。

        直近の大会のエントリー

          人員表の「出場」に入っている人（選手として出る競技と馬）。終わった大会は出さず、次の大会に切り替わります。

          朝練の馬配

          この日の一限・乗らない人

          一限は部員がマイページで曜日ごとに入れたものが最初から付いています。この日だけ違うときはここで直します。「乗らない」にした人は自動で組むときに入れません（鞍なしなど）。休み・無断の人は上の欄のとおりで、ここでは選べません。

            まだ組んでいません。「自動で組む」を押すと、上の欠席を外して組みます。

            馬休の馬は下の「馬休」に並び、手入れの人は自動でその馬のチーフ（ほかの馬には乗せない＝鞍なし。足りないときだけ乗る）。手入れの人のマグネットを押すと選び直せます。人が足りなくてだれも乗らない馬が残るときは、もう片方の時間の人が二頭目に入ります（チーフ → 最近の二頭乗りが少ない人。一限の人は後半にしない）。手で入れるときは「＋ 足す」の「二頭目として足す」。無断の残りがある人（要注意）は、来ていても乗せません（来た日に残りが1つ減ります）。自動で組むときは、チーフ → 自分の馬の1鞍目、チーフがいない馬 → できるだけ学年が高い人が1鞍目、直近の大会にエントリーしている人 → その馬、一限の人 → 前半の馬、残りの人は乗る人の少ない馬から均等に入れます。人のマグネットを2回タップすると、その2人が入れ替わります（同じ馬の中なら鞍の順が入れ替わる・下の「まだ」の人とならその人と交代）。1人選んでから馬のマグネットを押すと、その馬の最後へ移ります。馬のマグネットを2回タップすると、乗る人ごと2頭の場所が入れ替わります（前半と後半の馬なら枠も入れ替わる）。掃除は自動で組むと後半鞍の人から最近の掃除が少ない順に入ります（馬からは降ろしません）。左の欄に掃除場所を打ち込めます（新しく組むと前の日の場所が入っています）。人を選んで「＋ここへ」で足す、掃除の人とほかの人を2回タップで交代、× で外す。もう一度押すと選ぶのをやめます。× で外す、「＋ 足す」でほかの馬から選ぶとその馬から移ります。
