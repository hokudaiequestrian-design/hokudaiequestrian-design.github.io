← マイページ使い方

自分のぶんだけ読めば足ります。印刷すると全部出ます。

部員用の使い方

出すものは4つ（大会の出欠・手入れの希望・休みの申し込み・当番の希望）。パスワードは要りません。

1. 開く

配られたURLを開いて、自分の名前を選ぶ 名前は次から覚えているので、選び直すのは人が変わるときだけです。このページをブックマークしておくと、毎回ここから入れます。

マイページには、これからの予定（大会・手入れ・当番・休み）と、まだ出していないものが出ます。出すものが残っていれば、そこから開けます。

2. 出すもの

大会の出欠を出す大会の日ごとに「行ける・行けない」を答えます。出る競技と馬があれば入れます。出場する競技には仕事が当たりません。
手入れの希望を出す自分がサブに入っている馬のうち、いま募集している期間の日に ◎（入りたい）・○（入れる）・×（入れない）を出します。全部の日に出してください。出していない日は担当に入りません。
募集していないときは「いまは希望を受け付けていません」と出て、出せません（出したぶんは見られます）。
休みを申し込む有給休暇と季節休みを申し込みます。みんなの休みとバイトもここで見られます。
当番の希望を出す昼当・夕当・投げ草の希望を4つ選びます。受付中の期間だけ出てきます。出ていないときは、まだ募集していないか、もう締め切られています。

3. 休みのきまり

  • 有給休暇は1年度に決まった日数まで。残りはマイページと申し込みの画面で見られます。
  • 申し込みは先着順で副将が了承します。了承されるまでは「了承待ち」です。
  • 過ぎた日の休みは取り消せません。早めに申し込んでください。
  • バイトは副将が入れます。自分では申し込めません。
  • 了承された休み・バイトの日は、手入れの担当から外れます。

4. 人員表を見る

副将が公開した大会の人員表を、全員ぶんそのまま見られます（見るだけで、直せません）。 自分の行は黄色くしてあります（マイページで名前を選んでおいてください）。
公開されるまでは出てきません。カレンダーの大会の日も、公開されるまでは「大」のままです。

5. 朝手入れ

朝手入れはふつうの手入れとは別枠です。手入れは毎日ありますが、朝手入れは朝練が休みの日だけなので、 入っていない日があっても間違いではありません。◎○× は出しません（チーフが決めます）。

  • チーフがカレンダーで組んでいる馬 … カレンダーの「手入れ予定」に「朝」の札で出ます。
  • チーフがローテーションで組んでいる馬 … 「手入れの希望を出す」画面のいちばん下に回る順番が出ます（日付は決まっていません）。

6. カレンダー

マイページの「カレンダーを見る」で、決まった手入れの担当とみんなの休みを月ごとに見られます。

  • カレンダーのタブ … 人ごと・日ごとの表。大会の日は、人員表ができると仕事の1文字に変わります （出＝出場する選手（赤）、下＝その馬に付く人、運・箱・在 などは仕事名の1文字目）。 仕事の1文字は人員表と同じ色で塗ってあります（何の仕事かは上の帯に出ます）。 人員表がまだのあいだは「大」です。
    大会のぶんは必ず1文字です。1日にいくつ入っていても、強いほうから 出 →（在以外の仕事）→ 下 → 在 の順で1つだけ出します。 同じ強さのものが並んだら、その日の競技の早いほうです。
    休み・バイトと大会が同じ日になっているときだけ、気づけるように2つ並べて出します（どちらかが間違いです）。
  • 当番・手入れ予定のタブ … 月ごとではなく、きのうから30日ぶんが出ます（＜＞で30日ずつ送れます。「きのうから」で戻ります）。日ごとに、当番は昼当｜夕当｜投げ草の列、その下の段に手入れ（馬 名前）と朝手入れ。 いちばん上に自分のこれからの予定が並び、押すとその日へ飛びます（マイページで名前を選んでおくと出ます）。 「自分だけ」で自分の日だけに、馬を選ぶとその馬の手入れだけになります。
リンクが開かないとき マイページの下にある「リンクが開かないときは」を開いてください。Googleに2つ以上のアカウントでログインしていると起きます。直らないときは、出ている画面をそのまま撮って副将に送ってください。

チーフ用の使い方

部員として出すもの（4つ）に加えて、担当する馬の手入れをまとめるのがチーフの仕事です。

鍵 「手入れをまとめる」はチーフパスワードが要ります。副将のマイページからログインしている人は、そのまま開けます。

手入れ表ができるまで

1. 馬を選ぶ自分が担当する馬を選びます。馬のチーフを決めるのは副将です。
2. 期間を選ぶ・作る期間の行を押すと開きます。新しく作るときは「期間を新しく作る」から、名前（後期・夏休みなど）と作り方を決めます。
・曜日＝毎週おなじ担当　・カレンダー＝日付ごとに決める（最長400日）。どちらも開始日を入れてください。
3. サブを選ぶ期間名の横の鉛筆を押すと「期間の編集」が開きます。ここでチーフの割合を決め、この馬を手入れする人にチェックを入れます（手入れは1日1人で組みます）。チーフ本人もサブに入れてください。選んだ人にだけ、部員の画面に◎○×の欄が出ます。
4. 希望を募集する・締め切る期間の編集の「希望の受付」のチェックで切り替えます。
・入れる＝部員の画面にこの馬が出て、◎○× を出せます　・外す＝「いまは希望を受け付けていません」と出て、出せなくなります
出ている票と手入れ表は、締め切っても消えません。締め切ったあとも代理入力はできます。
5. 投票を待つ・代理で入れる「投票状況」で、誰が出していないか分かります。出せない人のぶんは代理で入れられます。
6. 手入れ表を作る「作成する」を押すと、×の日を避けて◎の人から順に入ります。チーフは、ほかのサブより多め（既定でチーフ2：ほかのサブ1）に入ります。

手で直す

  • カレンダーの上の「編集」を押すと、日を押して担当を選べます。プルダウンはサブだけで、上から ◎入りたい → ○入れる → ×入れない → まだ出していない の順です。
  • 一覧にない人（OBなど）は「✎ 名前を書く」で名前を打てます。
  • 「この日を空にする」で、その日の担当を外せます。
  • 手で入れた担当には鍵が付きます。鍵の付いた担当は、作り直しても動きません。
  • 直したら保存を押してください。保存していないときは画面の下に帯が出ます。

朝手入れ（手入れとは別枠）

朝手入れは朝練が休みの日だけのものです。期間は作りません。 馬のカードのすぐ下にある「朝手入れ」を開いて設定を変えると、それがそのまま新しい決まりになります。 いまどちらで動いているかは、「朝手入れ」の横に出ています。

  • カレンダー＝日付ごとに担当を決めます。日を押してサブから選び、「保存」を押します。 朝練がある日は空のままで大丈夫です（足りない日の知らせは出しません）。 決めたぶんは、みんなのカレンダーの「手入れ予定」にだけ出ます。
  • ローテーション＝サブの並び順で1人ずつ回します。日付は決めません。 「上へ」「下へ」で順番を入れ替えて「保存」を押すと、サブの画面にだけその順番が出ます。
  • どちらか片方だけが動きます。切り替えても、もう片方に入れた中身は消えません。
  • ◎○× は集めません。その馬のチーフが決めます。
気をつけること ・サブを外すと、その人のその馬の◎○×と、手入れ表に入っているぶんも消えます。
・期間を消すと、サブ・投票・手入れ表も消えます。
・了承された休み・バイトの日は担当から外れます。warnings（気になるところ）に出ます。

副将用の使い方

ログインは1回だけ 副将のマイページでパスワードを入れると、当番・手入れと人員表の両方にログインします。タブを閉じるまで、どの画面でもパスワードを聞かれません。閉じたら入れ直してください。パスワードは人に配らないでください。
了承待ちの休みは、マイページのいちばん上に出ます ログインすると、まだ了承していない休みの申し込みが赤い帯で出ます（だれが・何の休みを・いつ・何日ぶん）。 そのまま「休みをまとめる を開く」で決めに行けます。0件のときは何も出ません。 中身はパスワードを入れたあとに出るので、ログインする前は出ません。

1. 部員・馬匹管理

  • 名簿は人員表と当番・手入れで1つです。ここで足す・直す・消すと、両方に入ります。
  • 4年生以上は、足したときから「当番に入れない」が付きます。
  • まとめて足すときは、1行に1人（名前・入部年・役職・備考）で貼り付けます。
  • 「馬とチーフ」で、馬とその馬のチーフを決めます。チーフを決めるのは副将だけです。
  • 「サブ整理」は、開始日ごとに決める馬ごとの基本のサブです。チーフが期間を作るときに「最新のサブ整理に合わせる」で使えます。
  • パスワード（副将・チーフ）を変えるのも、この画面のいちばん下です。

2. 人員表をまとめる

  1. 大会・競技設定で大会を作り、日ごとの競技と仕事の必要人数を入れます。競技名は「まとめて追加」に1行1競技で貼れます（開催順に並べてください）。
  2. 部員が出欠を出したら、出場する競技と馬を確かめます（足りなければここで直せます）。
  3. 人員表で「自動生成」。出られない人・出場する競技には当てません。足りない競技は色で出ます。 表は日がかわるところで太い縦線が入り、1日おきに見出しの色が変わります。名前・役職・状態は1行に並びます。
  4. 手で直すときは表計算ソフトと同じ感覚で：マスを選んで（ドラッグで何マスでも）表の上の仕事の札を押すと、選んだマス全部に入ります（札の番号の数字キーでも）。 札の数字は、その競技に入っている人数／要る人数です。文字を打ち始めるか Enter で名前から絞り込んで入れることもできます（Enter で決めて下へ、Tab で右へ）。 選んだ範囲の右下の小さな四角を引っぱるとその先へ写せます。競技の見出し・名前を押すと列・行をまとめて選べます。 列が多いときは「表を広げる」で画面いっぱいに（Esc か同じボタンで戻ります）。
  5. 直したら保存し、⋯ からExcel に書き出して配ります。
  6. 部員に公開する：押すと、部員の「人員表を見る」に表が出て、 みんなのカレンダーの大会のマスも「大」から仕事の1文字（出・下・運…）に変わります。 押すまでは出ませんので、作りかけを見せずに済みます。「公開をやめる」で戻せます。
    場所は2か所：大会一覧の行のボタンと、人員表のタブ（自動生成の下の欄。そこで仕上げるので、戻らずに公開できます）。 どちらにも「部員に公開中／まだ公開していません」の印が出ます。

3. バイト・休みをまとめる

  • 申し込み：先着順に「了承する」。却下や記録ごと消すのは ⋯ の中です。
  • 休みを入れる：部員の代わりに副将が入れる欄です。
  • バイト：「どのバイト」の下の ＋ でバイト先を作り、カレンダーの日を押して、学年ごとに並んだ名前を押すと入ります。もう一度押すと外れます。入れた日はその人の休み（バイト）になります。
  • 自動で入れる：カレンダーの下の「自動で入れる」を開きます。 まずその日に要る人数を決めます。カレンダーのマスの ＋ と − で1人ずつ直せるほか、 曜日ごとにまとめて入れる欄と「この月ぜんぶに入れる」もあります。決めたら「要る人数を保存」。
    そのうえで「この月を自動で入れる」を押すと、2段で組みます。 ①だれが出るか＝その月に要る人数の合計ぶんを、順位の上の人から取ります （1人が同じ月に取れるのは2回まで。「1か月に入る上限」で変えられます）。 ②いつ行くか＝取った人を、人が要る日の中へランダムに配ります。
    • 学年ごとの回数の差を決めておきます（1年を基準にした「下駄」。既定は1学年ごとに6回）。 上級生ほど多く行くので、そのままだと下級生ばかりが入ってしまうためです。 同じ学年の中では、回数の少ない人から入ります。
    • 下駄を引いた回数まで同じ人が並んだらランダムです。押すたびに結果が変わります。
    • 1か月に同じ人が入るのは2回まで（「1か月に入る上限」で変えられます）。
    • 休み・ほかのバイトと重なる日、大会がある日には入れません。
    • 「自動で入れない人」にチェックした人は入りません（手では入れられます）。
    • 手で入れたぶんには鍵が付き、組み直しても動きません。鍵の無いぶんだけ入れ替わります。
    • 「組んで中身だけ見る」で、保存せずに結果だけ見られます。
  • 行った回数：カレンダーに入れた日を数えます（入れた瞬間に増え、外すと減ります）。システムに入れる前のぶんは「回数を編集」で足せます。この数は部員には見えません。
  • 決まり：有給の日数、年度の始まり月、了承ずみの休みを手入れの担当から外すか。

4. 当番をまとめる

  1. 当番の設定：期間（前期・後期など）と当番（昼当・夕当・投げ草）、曜日ごとの必要な学年を決めます。期間の「受付中」のチェックで、当番の希望を集めるかどうかを切り替えます（受付中でない期間は部員の画面に出ません）。
    期間に開始日と終了日を入れると、その範囲の日にカレンダーの「当番・手入れ予定」へ出ます（2026-09-21）。空のままなら出ません。
  2. 投票状況：誰が出していないか見られます。代理でも入れられます。
  3. 当番表：作って、手で直して、保存します。手入れの期間もここから作れます。

5. 手入れをまとめる

チーフと同じ画面です。チーフが決まっていない馬や、チーフが手を付けられないときに副将が代わりに作れます。使い方は「チーフ用」を見てください。

手入れの希望の募集も、この画面の「期間の編集」→「希望の受付」で切り替えられます（馬ごと・期間ごと）。

配るURL

部員に配るマイページのURL（そのまま）
チーフに配るマイページのURLに ?role=chieflinks を付けたもの
副将が持つマイページのURLに ?role=admlinks を付けたもの（配らない）

この3本だけ配れば足ります。中の画面へは、それぞれのマイページから入れます。
